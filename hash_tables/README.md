# C - Hash Tables

## 📌 Description
This project is about implementing hash tables in the C programming language.  
It demonstrates how to create a hash table, store key-value pairs, and handle collisions.

## 🧠 Concepts
- Hash tables
- Hash function
- Key-value pairs
- Collision handling (chaining)
