C - Hash Tables
📌 Description

This project focuses on implementing hash tables in the C programming language.
It covers how to create a hash table, store data using key-value pairs, and handle collisions.

🧠 Concepts
Hash function
Hash table
Key-value storage
Collision handling (Chaining)
⚙️ Functions
hash_table_create → Creates a new hash table
🛠️ Compilation
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o hash_table
▶️ Usage
./hash_table
