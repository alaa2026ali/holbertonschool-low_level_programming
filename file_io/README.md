# File Descriptors

## Description

This project is about using system calls in C to handle files (open, read, write, close).

## Learning

* File descriptors (0: input, 1: output, 2: error)
* System calls: open, read, write, close
* File flags: O_RDONLY, O_WRONLY, O_RDWR
* File permissions

## Requirements

* Ubuntu 20.04
* gcc -Wall -Werror -Wextra -pedantic -std=gnu89
* Betty style
* No global variables

## Restrictions

* Allowed: malloc, free, exit
* Syscalls: read, write, open, close
* No printf or similar
